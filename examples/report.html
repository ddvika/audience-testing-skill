Для расчёта нужны исходные данные

Поведение AI-агентов
не определяет retention или CAC.

В этом отчёте нет исходных данных для числового прогноза. Для расчёта нужны данные о трафике, расходах, конверсии и возвращении пользователей.

Каких данных не хватает
  • Для CAC: monthly_visitors, marketing_spend и paid_conversion [low, high] из внешних данных.
  • Для MAU: внешний диапазон mau [low, high] с определением активного пользователя.
  • Для среднего DAU: mau и active_days [low, high] на пользователя за 30 дней.
  • Для возвращений: return_rate [low, high] из аналитики с окном наблюдения и когортой.
