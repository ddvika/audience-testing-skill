## Release title

Audience v0.3.1 — product testing with evidence

## Release notes

Audience turns a product URL, a research question and a spending cap into a browser-based study with AI personas.

- Automatic or manual selection of personas and OpenRouter models.
- Several personas in one authorized account, with separate product conversations and model histories.
- An explicit experiment design, recorded task outcomes and evidence-linked product priorities.
- A lightweight offline HTML report with a dialogue appendix and TXT/JSON export for captured conversations.
- Budget accounting, bounded waiting, run deadlines and host checkpoint recovery.
- A fictional sample report and offline validation suite.

The recommended route uses an assistant's authorized browser through the host bridge. The standalone Playwright route remains experimental. Claude execution has not been validated end to end. The report interface is currently Russian.

AI personas are simulations. Synthetic satisfaction and willingness to return do not establish real retention, CAC, DAU or MAU. Conditional forecasts require explicit external assumptions.
